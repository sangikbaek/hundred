# 의료기기 3D 탐색기

Three.js 코드만으로 만든 의료기기 3D 모델 모음입니다. 외부 3D 파일(GLB/OBJ) 없이 모든 부품을 코드로 만들었고, 버튼을 누를 때마다 기기가 움직입니다.

| 페이지 | 내용 |
| --- | --- |
| [`index.html`](index.html) | 대장내시경 — 회전·분해·조립·굴곡·대장 진입·선단부 |
| [`surgical-robot.html`](surgical-robot.html) | 다관절 수술로봇 — 회전·도킹·분해·조립·원격 조종·손목 |

화면의 부품을 누르거나 오른쪽 "부품 바로가기"를 누르면 그 부품의 설명이 나옵니다. 끌면 돌려 보고, 휠이나 두 손가락으로 확대합니다.

## 실행

빌드 과정이 없는 HTML 파일입니다. three.js는 jsDelivr CDN(`three@0.170.0`)에서 불러옵니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 (대장내시경) 또는
# http://localhost:8000/surgical-robot.html (수술로봇) 열기
```

GitHub Pages로 올리려면 저장소의 Settings → Pages에서 이 브랜치의 루트(`/`)를 선택하면 됩니다.

## 대장내시경 3D 탐색기 (`index.html`)

| 버튼 | 하는 일 |
| --- | --- |
| **회전** | 기기를 턴테이블처럼 천천히 돌립니다. 다시 누르면 멈춥니다. |
| **분해** | 노브, 밸브, 스위치, 겸자 마개, 삽입부, 만곡부, 선단부, 유니버설 코드, 커넥터가 순서대로 떨어져 나옵니다. 삽입부가 반투명해져 안쪽의 앵글 와이어·광섬유·영상 케이블·채널이 보입니다. |
| **조립** | 분해된 부품이 역순으로 제자리에 돌아갑니다. |
| **굴곡** | 앵글 노브를 돌려 만곡부를 상하(±180°)·좌우(±160°)로 꺾습니다. 자동 시연이 돌고, 슬라이더로 직접 꺾을 수도 있습니다. |
| **진입** | 대장 해부도(직장 → S상 결장 → … → 맹장)를 따라 내시경이 들어가고, 내시경 화면에 선단 카메라 시점이 나옵니다. 끝까지 가면 빼면서 관찰할 수 있습니다. |
| **선단부** | 선단부를 확대해 대물렌즈, 라이트 가이드, 송기·송수 노즐, 겸자 채널 출구, 워터젯을 보여 줍니다. |
| **초기화** | 처음 상태로 돌아갑니다. |

코드로 만든 구조:

- **조작부**: `LatheGeometry`로 손잡이 단면을 회전시켜 만들고, 앞뒤로 살짝 눌러 타원 단면으로 만듦
- **앵글 노브**: 홈이 파인 외곽선을 `ExtrudeGeometry`로 돌출. 굴곡 각도에 따라 실제로 회전
- **밸브**: 캡 + 스템 + 나선 스프링(`TubeGeometry` + 나선 곡선). 분해하면 축 방향으로 빠져나옴
- **삽입부**: `CatmullRomCurve3` 경로를 따라 만든 관. 10 cm·5 cm 깊이 눈금은 캔버스 텍스처
- **만곡부**: 12마디 관절 체인. 노브 값(상하·좌우)을 하나의 굽힘 축과 각도로 바꿔 각 마디에 나눠 줌
- **대장**: 해부 경로를 따라 단면을 직접 생성. 결장 주름(haustra)과 삼각형 내강, 맹장 끝의 막힌 부분을 반지름 함수로 표현. 바깥면(반투명 해부도)과 안쪽 면(점막·혈관 텍스처)을 레이어로 나눠 메인 화면과 내시경 화면에 따로 보여 줌
- **내시경 화면**: 선단에 붙은 별도 카메라와 점광원, 안개로 깊이감을 표현. 굽은 구간에서는 선단이 다음 내강 쪽으로 꺾임

## 수술로봇 3D 탐색기 (`surgical-robot.html`)

다빈치처럼 팔이 여러 개인 복강경 수술로봇의 일반적인 구조입니다. 환자 측 카트(팔 4개), 수술대와 환자, 서전 콘솔, 비전 카트가 한 장면에 있습니다.

| 버튼 | 하는 일 |
| --- | --- |
| **회전** | 장면을 천천히 돌립니다. |
| **도킹** | 카트가 굴러와 붐을 환자 위로 돌리고, 팔을 펼쳐 캐뉼라에 연결한 뒤 기구를 넣습니다. 오른쪽 패널에 5단계가 표시됩니다. 페이지를 열면 한 번 자동으로 재생됩니다. |
| **분해** | 베이스·컬럼·붐·플랫폼과 각 팔의 셋업 관절·로봇 팔·기구 레일·구동부·기구·캐뉼라가 떨어져 나오고 이름표가 붙습니다. 기구가 몸 밖으로 빠져 손목 끝이 보입니다. |
| **조립** | 분해된 부품이 제자리로 돌아갑니다. |
| **원격 조종** | 콘솔의 마스터 컨트롤러 움직임이 줄어들어(1:1 · 3:1 · 5:1) 기구 끝으로 전달됩니다. 떨림 보정을 켜고 끌 수 있고, 내시경 팔의 카메라 화면(봉합 중인 조직, 바늘, 실)이 작은 창으로 나옵니다. 기구가 포트(원격 운동 중심)를 축으로 움직이는 모습도 볼 수 있습니다. |
| **손목** | 손목 기구 끝을 크게 확대해 피치·요·그립·회전을 슬라이더로 움직입니다. |
| **초기화** | 처음 상태로 돌아갑니다. |

코드로 만든 구조:

- **로봇 팔**: 플랫폼의 팔 시작점과 기구 레일 꼭대기를 두 마디 역기구학(IK)으로 이어, 기구 방향이 바뀌면 팔 전체가 따라 움직임
- **원격 운동 중심**: 기구는 항상 포트를 지나도록 `방향 = (목표점 − 포트)`로 계산하고, 넣은 깊이만큼 구동부가 레일을 따라 오르내림
- **손목 기구**: 피치 관절(케이블 풀리) + 요·그립 관절(집게 두 개가 같은 축에서 회전). 확대용과 로봇에 달린 작은 기구가 같은 코드
- **환자와 멸균 천**: 몸 모양 높이 함수로 천을 덮고, 수술 부위만 피부가 드러나는 텍스처
- **몸 안**: 복벽·장·지방·봉합 중인 조직을 내시경 화면 전용 레이어에 두고, 별도 캔버스에서 내시경 조명과 안개로 그림

## 참고

교육용 시각화이며 특정 제품을 재현하지 않았습니다. 상표나 로고도 넣지 않았습니다. 대장내시경의 길이·외경·채널 내경·만곡 각도와 수술로봇의 기구 지름·동작 축소 비율 등은 일반적인 예시 값이고, 해부 구조와 크기는 이해를 돕기 위해 단순화했습니다.
